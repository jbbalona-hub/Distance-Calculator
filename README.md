# Conversion of Units

## Description
This program allows you to convert kilometers units into miles units

## How to run the program
1. Open the program in Programiz, VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the value of Distanceinkilometer and conversionfactor.
4. Check the output Distanceinmiles.
## Input needed
1. Distance in kilometer
2. Conversion Factor

## Sample Output
Enter Distance in kilometer:8
